## The game — not redistributed here

GodhomeRL **does not ship, download or redistribute any part of the game.** It
builds a patched copy from an installation you provide, into `build/`, which is
git-ignored.

| Component | Author(s) | Licence |
| --- | --- | --- |
| [Godhome](https://github.com/vitellaryjr/Godhome) | its contributors | see `license.txt` in the Godhome standalone download |
| [Kristal](https://github.com/KristalTeam/Kristal) | the Kristal Team | GPL-3.0 |
| LÖVE | LÖVE contributors | zlib |
| [Hollow Knight](https://www.hollowknight.com) | Team Cherry | proprietary — **not required**, Godhome is a standalone fan game |
| [Deltarune](https://deltarune.com) | Toby Fox | proprietary — **not required** |

`build/` contains a modified copy of Kristal (GPL-3.0) because the harness
injects a `require` line into `main.lua`. That copy:

* is never committed,
* is regenerated by `python -m godhome_rl build`,
* stays on your machine.

If you distribute a `build/` directory or an executable produced by it, you are
distributing a derivative of GPL-3.0 software and must comply with that licence
(most practically: provide the corresponding source, which is
`build/game/main.lua` plus the eight files in `build/game/rl/` — all of which
came from this repository under MIT, with `build/game/` otherwise being the
Kristal and Godhome sources you supplied).
